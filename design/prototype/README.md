# Mnema — бумажный интерактивный прототип

Самостоятельный HTML/CSS/JS макет выбранного владельцем направления. Это инструмент
обсуждения, не реализация Learning API, авторизации или алгоритма повторений.
Оригинал в Downloads не изменён. Зависимости приложения не менялись.

Запуск из корня репозитория:

```sh
node design/prototype/serve.mjs
```

Откройте http://127.0.0.1:4173. Сервер слушает только loopback. Завершение — Ctrl+C.
Можно также открыть `index.html` напрямую, но для одинаковой загрузки шрифта и
проверок рекомендуется локальный сервер. Никаких внешних запросов, аккаунта или
установки пакетов для работы не требуется.

## Что попробовать

1. Лендинг: ссылки в шапке, три плитки и обе бумажные выноски прокручивают страницу
   к содержательным разделам. Футер расположен после них, шапка не закреплена.
2. «Начать с моей колоды» → собственные колоды → English. В ней слова и грамматика.
3. «На потом»: добавить фрагмент → «Разобрать» → заполнить материал и обе стороны
   упражнения → сохранить. Фрагмент исчезает из списка только после сохранения.
4. Serendipity: длинный материал, предпросмотр, отдельные короткие стороны упражнения.
   Поменяйте ответ, сохраните, посмотрите номер редакции. Изменение не сбрасывает обучение.
5. Занятие: открыть ответ, оценить себя, соединить пары, ввести короткий ответ.
   Matching демонстрирует только словарные материалы; для одной новой записи его нет.
6. После завершения — материалы, точный повтор снимка занятия или практика с новым
   seed. Дополнительные режимы не меняют основной demo completion flag.
7. Создайте пустую колоду: от пустого состояния можно перейти к новому материалу.

Все данные существуют только в памяти вкладки и исчезают при перезагрузке. Это
ограничение макета, не продуктовая политика сохранности. В макете один восстанавливаемый
редактор в памяти; серверные множественные drafts ещё не реализованы. Доступен
plain-text редактор, без реальной загрузки/проигрывания медиа, AI и rich-text дерева.
Расписание, mastery, streak, счётчики, дата календарного дня и авторизация не
вычисляются. «Учить заново» показывает пояснение будущего подтверждения без сброса.
Практика ограничена 2–3 демонстрационными заданиями; не является обходом всей колоды.
Упражнения привязаны к демонстрационной модели, конструктор произвольных M:N bindings
описан в design doc. Не переносить этот state/router в Angular как архитектуру.

## Файлы и происхождение

- `index.html`, `styles.css`, `app.js`: локальный самодостаточный прототип.
- `assets/mnemosyne-engraving.png`: новая растровая гравюра, созданная главным агентом
  по выбранному пользователем изображению; не вектор и не музейная фотография.
  [Происхождение и prompt](./assets/mnemosyne-provenance.md).
- `assets/celestial-cloud.svg`: оригинальный кодовый декоративный мотив облака.
- `assets/CormorantGaramond.ttf`: upstream Google Fonts / Cormorant Garamond,
  [официальный каталог](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond),
  получен 2026-09-06. Лицензия SIL OFL 1.1 в `assets/OFL-CormorantGaramond.txt`.
  Полный TTF намеренно локальный; для production требуется WOFF2 subset с кириллицей.
- `screenshots/`: визуальные свидетельства desktop 1440 px и mobile 390 px.
- `contrast-pairs.json`: четыре основные пары для проверки контраста.

## Проверки 2026-09-06

Проверены синтаксис Node, браузер Chromium через Playwright, связанные переходы,
создание колоды/заметки/материала, обязательность обеих сторон, pending save,
редакция после сохранения, matching неверных/верных пар, typed feedback, replay seed,
отсутствие изменения demo completion при практике, буквальное отображение HTML в
пользовательской записи, reduced-motion якоря и управление Enter/Tab.
Скриншоты сохранены для лендинга, колоды, редактора и занятий. Перепроверены ширины
320, 390, 768, 1440 после исправления узкого заголовка и декоративного overflow.
Console errors/warnings в проверенных сценариях отсутствуют.

Основные контрасты: ink/paper 12.679:1, body/paper 11.382:1, muted/paper 5.615:1,
sheet/ink 13.595:1 — все четыре проходят WCAG AA для обычного текста. Это не проверка
всех возможных состояний. После ухода со страницы во время 350 ms demo-save запись
сохраняется в исходной колоде, навигация не возвращает пользователя в редактор.

Это не независимый аудит доступности и не performance/load benchmark. VoiceOver,
TalkBack, реальные iOS/Android, Safari, Firefox, offline sync и production quality
gate данным прототипом не проверены. Главный агент отдельно запускает gate репозитория.
