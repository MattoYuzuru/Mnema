# Mnema — прототип онбординга

Кликабельный прототип «Начала пути», spotlight-тура, «Пути» и ритма, утверждённый владельцем 2026-10-16.
Design evidence, не реализация (реализованное поведение — [proposal](../../../docs/engineering/onboarding/proposal.md)): нет API, авторизации и сохранения, состояние живёт во вкладке.
Роутер и состояние не переносить в Angular — архитектура в
[architecture §8](../../../docs/engineering/onboarding/architecture.md#8-frontend). Решения Q01–Q13
([решения владельца](../../../docs/engineering/onboarding/README.md#решения-владельца)) прототип показывает, а не переспрашивает.
Зависимостей нет: HTML, CSS, ES-модули.

```sh
node design/prototype/serve.mjs
```

Откройте http://127.0.0.1:4173/onboarding/index.html. Сверху — панель прототипа (не часть продукта):
список экранов, «Спокойное движение» (вид при reduced motion) и «В каталоге ≥ 4 колод» (показывает или
скрывает ветку «Найти готовую колоду»). Параметры адреса: `?shot` прячет панель, `?calm`, `?catalog=0`;
экран — в `#hash`.

## Экраны

| Экран | `#` | Что показывает |
|---|---|---|
| Приветствие | `welcome` | Ночная поверхность, звёзды мотива `app-deck-constellation` (лавандовые и бумажные), две кнопки одной высоты |
| Пропуск | `skip` | Тост со ссылкой «Открыть «Путь»» |
| Опрос | `survey-1…4` | Та же ночная поверхность без звёзд (Q12), полоса прогресса, «Пропустить» на каждой карточке, строка о данных; дни — вид `app-segmented-choice` |
| Выбор пути | `branch` | Без звёзд; три варианта; «Найти готовую» скрыт без каталога; штамп «Советуем для начала» новичку |
| Spotlight | `tour-sample-1…4`, `tour-community-1…4`, `tour-own-1…4` | Чернильная вуаль без звёзд, вырез с лавандовой рамкой, карточка «Шаг N из M», точки, «Назад»/«Дальше»; информационный шаг — `showModal()`, шаг с действием — `show()` (ADR-ONB-001) |
| Мини-слайдер | `tour-sample-2` | Три пояснения одного места внутри шага (не новые шаги) |
| Action-gate | `tour-sample-4`, `tour-community-3` | Нет «Дальше»; шаг закрывает нажатие на цель; остальная страница `inert` |
| «Не нашли?» | `community-stuck` | Подсказка у поиска (45 с) и карточка «Создайте свою» (2 мин) |
| Пауза | `pause` | Escape в туре → плашка «Продолжить знакомство» на той же странице, фокус на ней, возврат к тому же шагу |
| Завершение | `finish-states`, любой шаг тура | Три состояния: подпись → знак «палец удерживает» без подписи → заливка; тост `finished` |
| Финал | `ai-final` | Карточка «ИИ в Mnema» на вуали, ссылка «Тарифы» без автоперехода |
| Поздравление | `congrats` | Звёздная поверхность, «Начало положено», без конфетти |
| «Путь» | `path` | 4 главы, открыта текущая, состояния вех знаком и словом, полоса «2 из 3», шеврон без тела с лавандовым hover; «Пройти знакомство заново» ведёт к выбору пути без опроса |
| Тост вехи | `path-toast` | «Путь: … · 6 из 13» |
| Подсказка на месте | `hint` | Без затемнения, у кнопки «На потом» |
| Ритм | `rhythm` | Итоги занятия: «Третий день на этой неделе», семь дней, цель, тост недели |
| Награда | `reward` | Поздравление 100 % с датой окончания текстом, без таймера |

Тексты — только из [texts.js](texts.js): утверждённый список (2026-10-16); продукт копирует их в
`frontend/src/app/core/onboarding/onboarding-texts.ts`, строки, добавленные реализацией, утверждены 2026-10-19.

## Уточнения дизайна (утверждены владельцем 2026-10-16)

1. **Мерцание звёзд конечное.** Proposal: «медленное мерцание»; контракт бренда запрещает бесконечную
   анимацию. Прототип: у части звёзд три цикла по 3,6 с, затем покой; при reduced motion — статично.
2. **Удержание при reduced motion** — заливка четырьмя ступенями без анимации (не «пусто»): во взведённом
   состоянии нет подписи с отсчётом, поэтому прогресс нужен иначе, чем у удаления.
3. **«Путь» — 4 главы** вместо 6 из таблицы вех (proposal просит 3–4): Начало · Материалы · Упражнения и ИИ ·
   Ритм и Сообщество.
4. **На телефоне** вырез прокручивается выше нижнего листа (страница получает отступ высотой листа).

## Проверки 2026-10-15

- [shots.mjs](shots.mjs) (Node 24 + CDP, без пакетов): 82 снимка в [screenshots/](screenshots/) —
  все 30 экранов на 1280, 14 ключевых на 768 и 320, взведённая кнопка, forced-colors (8 экранов × 1280/320),
  reduced motion (3 экрана); [shots.json](screenshots/shots.json): горизонтальной прокрутки нет ни на одном,
  при reduced motion нет идущих анимаций.
- Сценарий в Chromium (DOM-события): фокус на заголовке шага и объявление «Шаг 1 из 4…» в live-регионе;
  Escape → пауза; на action-gate шаге «Дальше» нет, `inert` у остальной страницы, нажатие цели → следующий шаг;
  первое нажатие «Завершить» → доступное имя «Удерживайте 2 секунды, чтобы завершить знакомство»; Escape
  снимает взвод, не ставя паузу; отпускание через 0,9 с ничего не делает; удержание Enter 2 с → тост.
- После независимого ревью (S0): звёзд нет на опросе и выборе пути; информационный шаг модальный
  (`:modal`), Escape → пауза с фокусом на «Продолжить знакомство» и возвратом к тому же шагу ветки;
  касание вне взведённой кнопки снимает взвод; ритм «Третий день», «Цель — 3 дня в неделю» (склонение через
  `Intl.PluralRules`); копия Сообщества — своя колода, без учебной плашки.
- Не проверено: VoiceOver/TalkBack, реальное касание, Safari/Firefox, 200 % масштаб, производительность.
  Это не аудит доступности; продуктовые проверки тура — в frontend-спеках и `scripts/browser-identity`.
