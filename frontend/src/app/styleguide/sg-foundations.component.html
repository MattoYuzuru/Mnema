Основы

Принципы

Mnema выглядит как современное учебное издание о памяти: бумага, чернила индиго, тонкие правила, почти прямые углы. Узнаваемость держится на типографике, пропорциях и тексте, а не на анимации. Источники: docs/frontend/design-and-experience-2026-09.md и docs/frontend/mnema-brand-and-ui-contract.md.

  • Бери из стайлгайда. У каждой задачи один компонент или класс. Нового элемента нет: сначала добавь его сюда, потом на экран.
  • Тишина по умолчанию. Цвет только там, где он что-то значит: чернила — действие, красный — ошибка, зелёный — успех, охра — внимание. Статус всегда назван словами.
  • Линия вместо рамки. 1 px правила, углы 2 px, тень только у наложенного листа. Рамка в рамке заменяется тонким разделителем.
  • Одна тема. Только светлая бумага: тёмной темы и режимов плотности в продукте нет, переключателей для них тоже.
  • Доступность — часть вида. Область нажатия не меньше 44 px, фокус виден, forced-colors и reduced motion не ломают смысл.
  • Один главный приём на экран. .generate-cta — не больше одного, декор снимается по мере роста нагрузки.

Основы

Радиусы и поверхности

Почти прямые углы (--mn-radius), тонкие правила, лист на бумаге. Тень допустима только у по-настоящему наложенного листа (окно «Попросить Мнему»). Карточка внутри карточки не нужна: разделяйте блоки линией.

Бумага--mn-paper: фон страницы
Лист--mn-sheet + 1 px --mn-rule: карточка, поле, редактор
Правиловерхняя линия --mn-ink: раздел без рамки
Заливка--mn-soft: выбранное, уведомление
