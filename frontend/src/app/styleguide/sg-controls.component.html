Фирменные приёмы

Три узнаваемых приёма. Каждый ограничен: если ставишь второй такой же на экран, приём перестаёт быть сигналом.

{{ deleted() ? 'Удержание завершено: в приложении здесь вызывается удаление.' : 'Нажмите, затем удерживайте кнопку.' }}

См. раздел «Движение».

Компоненты

Кнопки

Один класс .button с модификаторами. Страница добавляет только раскладку (.actions .button), а не второй вид кнопки. Подпись — глагол; недоступное действие остаётся в потоке с aria-disabled, если причину нужно объяснить.

Мои колоды →

Правило удаления: данные удаляются только через «Удаление удержанием» (раздел «Фирменные приёмы»). Убрать строку из ещё не сохранённой формы — обычная .button.small «Убрать»; красных кнопок удаления в продукте нет.

Компоненты

Поля ввода

Нативные input, textarea и app-mnema-select: подпись всегда видна, ввод не мельче 16 px, граница поля 3:1. Ошибка — предложение под полем с aria-invalid и aria-describedby.

Коротко, как в оглавлении.

} @else { }

Сохранится в «На потом».
