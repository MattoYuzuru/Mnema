# AI-слой Mnema: продуктовый контракт

Источник — голосовое ТЗ владельца 2026-10-01 и его ответы 2026-10-02 на итоги
исследования. Этот документ принимает продуктовые решения; архитектура — в
[AI generation platform](../architecture/ai-generation-platform.md), delivery —
в [Epic #77 refinement](../engineering/epic-77-refinement.md), исходные отчёты с
источниками — в [research index](../reviews/ai-layer-research-2026-10/README.md).
Он заменяет deferred-статус AI в [product direction](./product-direction-v2.md)
(D-04); тарифы и usage этого документа являются текущим продуктовым контрактом.
Юридические формулировки — не консультация.

## 1. Что строим

| Слой | Что входит в первый AI-релиз | Отложено |
|---|---|---|
| Генерация | материалы (из заметок «На потом», с нуля через composer), упражнения (из колоды, из multi-select материалов, из профиля материала), правки существующего материала/упражнения по выделению или инструкции, планировщик упражнений | AI-редактирование колоды целиком; удаление чего-либо по инициативе AI |
| Приём данных | speech-to-text в composer, окне правки, «На потом» и в ответах на упражнения; бесплатный fair-use | «live»-распознавание неотправленного ввода (гипотеза) |
| Проверка | семантическая проверка свободных объяснений (`ai-semantic`) с прогрессивной строгостью, текстом и голосом | AI-оценка произношения |
| Медиа | озвучка (TTS с кэшем), иллюстрации из лицензионных стоков, веб-поиск для фактчека по effort | генерация изображений (Pro/Max позже), видео (отдельный будущий тир) |
| Сквозное | Мастерская (батч + превью + правки), один usage-бар + fair-use + caps, центр уведомлений, статистика и хаб колоды, multi-select, paywall, промокоды, A/B-инфраструктура | email/push-уведомления |

Принципы: пользователь — соавтор, AI предлагает; ничего не попадает в колоду и в
Study до явного одобрения; текст дешёв, на контексте и качестве не экономим; медиа
и Free-аудитория ограничены caps; AI никогда не пишет `StudyState`.

## 2. Сценарии

- **S1 Из заметок.** Урок корейского → 10 заметок «На потом» → чекбоксы → composer с
  настройками → батч материалов в Мастерской → одобрение по одному или «все готовые».
- **S2 С нуля.** «Новый материал» → composer «Юзуру, что будем учить сегодня?» →
  превью → одобрить / править самому / оставить в Мастерской / удалить (hold 3 с).
- **S3 Упражнения для колоды.** Хаб колоды показывает покрытие → «Упражнения с ИИ» →
  билдер (механики, приоритет, количество / Авто / % бюджета, «Сначала показать план»)
  → фон → уведомление → экран проверки партии → «Сохранить выбранные (14)» → метка
  «Новое» → сессия.
- **S4 Из профиля материала.** «Попросить Мнему…» → «все типы по 3» → план-чипы →
  подтверждение → партия → редактор #267 или AI-правка.
- **S5 Правка по выделению.** Абзац → окно (пресеты + поле + микрофон при STT) →
  «слишком сложно» → блок переписан на месте → «Показать изменения / Оставить /
  Вернуть / Ещё раз». Картинка/аудио → «Найти похожее / Создать» / «Озвучить заново».
- **S6 Multi-select.** Выбор материалов → нижняя панель → «Упражнения с ИИ для
  выбранных» / «Удалить выбранные · 7» (hold).
- **S7 Объяснение.** Колода по PostgreSQL, упражнение «объясни, как работает
  оптимизатор»; первая встреча — мягкая проверка («верное направление и ключевые
  понятия»), «рецепт блинов» — не принимается; повторные попытки требуют полноты и
  терминологии. Ответ текстом или голосом; результат обычно за 2–3 с (p95 ≤8 с),
  на 5-й секунде доступно «Оценить себя», через 20 с — self-check без штрафа.
- **S8 Paywall.** Free выбран, рекомендуемый тир выделен по цели из онбординга, одна
  шкала AI-бюджета + отдельные счётчики голоса/проверок, неотмеченная галочка
  автопродления, отмена в один клик, промокод.

## 4. UX-решения

Подробные макеты, тексты и a11y-требования — в
[UX research](../reviews/ai-layer-research-2026-10/README.md); ниже — принятое.

- **Composer** — один компонент на три входа («На потом», «Новый материал»,
  «Упражнения с ИИ»): видимый label-приветствие «[Имя], что будем учить сегодня?»,
  поле запроса (Enter отправляет, Shift+Enter перенос, никогда во время IME-композиции;
  на телефоне — кнопка с `enterkeyhint="send"`), ниже настройки с прогрессивным
  раскрытием: подробность (Авто/Кратко/Средне/Подробно — native radio сегментами),
  вложения чипами с вложенными параметрами аудио, «Похоже на: как в колоде»,
  «Настроить для каждой заметки отдельно», «Сначала показать план». Пояснения — живым
  текстом под группой, длинные — toggletip. Preflight «≈ 6% месячного лимита»; при
  нехватке кнопка не выключается, нажатие объясняет варианты. Если AI недоступен —
  сразу обычный редактор.
- **Кнопка «Создать»** — индиговая CTA со «змейкой» по рамке только при hover/focus,
  3 круга, без радуги; reduced-motion — статичный блик; forced-colors — системная
  рамка; одна такая кнопка на экран.
- **Мастерская** — пейджер «3 из 10» с точками-статусами (форма передаёт статус без
  цвета), сводка «7 готово · 2 пишутся · 1 не удался», «Стоп»; блоки проявляются
  «чернилами» ≤600 мс по мере готовности, медиа — бумажная рамка-placeholder с
  `aspect-ratio`; «Одобрить и далее →» primary, «Отклонить» обратимо, «Удалить» —
  hold-to-delete, «Править самому» равноправно; «Одобрить все готовые (N)»; уход
  ничего не теряет; `aria-live` только для сводок.
- **Правка выделенного** — пункт «Попросить Мнему…» в существующей панели выделения
  редактора; немодальное окно с пресетами «Проще / Короче / Пример / Подробнее», полем
  и стоимостью; блок в состоянии «переписывает» остаётся читаемым (без opacity);
  результат с diff и версиями блока; на телефоне — нижняя панель `<dialog>`; микрофон —
  только при доступном STT. Медиа — существующий инспектор с «Найти похожее / Создать».
- **Хаб колоды** — «сначала читать»: описание, статистика, список материалов с числом
  упражнений и сортировкой «без упражнений сначала», звёздочка «Эталон», multi-select
  с нижней панелью действий; форма метаданных и удаление колоды — за «Изменить».
  Статистика — пять честных виджетов (покрытие упражнениями, где вы сейчас, ближайшие
  повторения, разнообразие механик, неразобранные заметки), inline SVG со штриховкой и
  таблицей-альтернативой; без opens/streak/mastery %.
- **Билдер упражнений** — тот же composer: механики из серверного registry (Авто),
  приоритет, количество (Авто / точно / «не больше 10% лимита» — взаимоисключающие),
  «Сначала показать план»; результат — экран проверки партии с предпросмотрами через
  `exercise-preview-host`, чекбоксы «Оставить», «Сохранить выбранные (N)», серверная
  метка «Новое» (снимается после открытия или через 7 дней).
- **Центр уведомлений** — «Входящие» + тосты; колокольчик в шапке с бейджем «99+»;
  тосты не live, озвучивает постоянный `role="status"`; пауза при hover/focus/скрытой
  вкладке; свайп + «×»; ≤3 видимых; во время занятия — до естественной паузы;
  настройка «Во время занятия: в паузах / сразу / только значок».
- **Имя и раскрытие** — «Мнема» в диалоговых местах, «ИИ» в подписях; toggletip «Что
  это?» рядом с первым AI-действием; страница `/ai` в футере («Как Mnema использует
  ИИ»: что делает, какие данные и кому уходят, лимиты); тон спокойный, книжный,
  ошибки вслух («Проверьте даты — я могла ошибиться»).
- **Paywall `/plans`** — персональный заголовок по цели онбординга («Для чего вам
  Mnema?»: экзамены и сессия / собеседование / язык / работа / для себя / пропустить);
  контекст лимита, если пришли от него; радио-карточки тиров, Free выбран,
  рекомендуемый выделен бейджем; 3 отличия в человеческих единицах («≈ 40 материалов
  с ИИ в месяц»); «≈15 ₽ в день»; «Сравнить подробно» таблицей; CTA меняется с
  выбором; отдельная неотмеченная галочка автопродления с суммой и датой; отмена и
  отвязка карты одним действием в профиле; FAQ «Все колоды остаются…»; поле промокода;
  Max — карточка «в работе» с тизерами.

## 5. Экономика

Себестоимость типовых операций (worst = peak, cache-miss, ×1,5 на repair, 100 ₽/$;
источники и upside — в economics research):

| Операция | Worst, ₽ | Вес, credits |
|---|---:|---:|
| Короткий / средний / подробный материал (DeepSeek V4.1 Flash) | 0,40 / 0,95 / 2,16 | 4 / 10 / 22 |
| 5 упражнений на материал | 0,72 | 8 |
| Правка по выделению / чат | 0,36 | 4 |
| AI-проверка одного ответа | 0,05–0,09 | fair-use |
| «Умный план» (Flash+thinking / Pro+thinking) | 1,98 / 7,52 | 20 / 75 |
| 1 мин STT (Groq turbo / self-host) | 0,07–0,13 / фикс. | fair-use |
| TTS-клип 30 с (400 символов) | 1,1–2,4; 0 при cache hit | 10 |
| «Подкаст» 3 мин | 7–15 | 75 (cap) |
| Поиск лицензированного изображения | 0,05 | 1 |
| Изображение эконом / качество (позже) | 0,7–1,4 / 3–7 | 15 / 60 (cap) |
| Фактчек low / high (15 запросов) | 0,8–1,6 / 3,7–16 | 15 / 120 (cap) |
| Видео 5 с (отложено) | 15–50 | 250–500 (cap) |

Порядки: 1 средний материал ≈ 1 озвученный клип ≈ 1 low-фактчек ≈ 10 минут STT.
Богатый контекст меняет картину: 25k входа при промахе кэша в peak ≈0,75 ₽, то
есть средний материал ≈1,5 ₽ worst (первые два артефакта сессии) и ≈0,4 ₽ при
попадании в prefix cache; rate card считает стоимость сессии, а не вызова, и
веса уточняются после 14 дней замеров.

**Модель usage.** 1 credit = 0,10 ₽ p95-себестоимости (внутренняя единица;
versioned rate card, веса пересматриваются через 14 дней замеров без ретроактивных
изменений). Пользователь видит проценты и «≈ N материалов». Один бар «AI-бюджет» на
создание; fair-use «Голос и проверка» вне бара — тихие счётчики с объяснением,
появляются при >80%; count-caps на подкасты, качественные изображения, high-фактчек.
Paid: месячный бар сразу, дневной burst ≤35%; Free: ¼ бара по понедельникам без
накопления; rollover — нет; «Буст +50%» — после recurring.

**Решения владельца 2026-10-02 (уточняют строку выше).** Free: порции 13, 13, 12, 12
(сумма = бар 50) накапливаются в пределах календарного месяца и не переносятся: первая

**Промокоды.** Типы: тир на N дней без продления («Plus на 15 дней»), тир на N

verified account, канал; защита: rate limit на endpoint активации (например, 5
попыток/час на аккаунт и IP), velocity по устройству/IP, kill-switch, аудит каждой
активации; выдаются только через admin-scope endpoint (простая админка — отдельная
задача). Промокод создаёт entitlement snapshot тем же путём, что и платёж.

**A/B и промо-попап.** Назначение вариантов — server-owned по account (детерминированно
по hash), метрика — ARPU и конверсия paywall плюс retention guardrail (D7/D30);
полноэкранный промо-попап: не чаще одного за сессию, cooldown 7–30 дней после
закрытия, никогда после покупки или отказа, не во время занятия и не поверх
редактора, всегда с явной кнопкой закрытия и без pre-ticked согласий.

**Что говорят данные о сравнениях цены.** Per-day framing (Gourville 1998; field-тесты
издателей +10–40%) работает для малых сумм (до ≈$4/день) и разворачивается для крупных;
Chung (2024) показывает риск ощущения манипуляции при нарушении нормы категории;
по данным Adapty/Airbridge копирайт-тесты выигрывают ≈35% случаев против ≈60% у
структурных (trial, число планов). Отсюда: «≈15 ₽ в день» — дефолт, «чашка кофе» —
A/B-вариант только для 449 ₽, структурные тесты (планы, trial, промо) — раньше
копирайта. Источники — в research index.

## 6. Legal и human gates

- Уведомление РКН о трансграничной передаче обезличенного учебного текста в DeepSeek
  (КНР — «адекватная» страна) до включения реальных пользователей; disclosure перед
  первым AI-действием; отдельное согласие на голос.
- Аккаунты провайдеров: DeepSeek (проверить оплату из РФ малым пополнением), OpenRouter
  (fallback текста), GigaChat через cloud.ru (опционально), Pixabay/Openverse ключи (Pexels убран
  2026-10-04), Google AI (Gemini TTS/транскрибация через шлюз), поисковый API.
- Egress-шлюз (2026-10-04): Google Gemini API terms ограничивают предоставление API-клиентов
  пользователям вне доступных регионов — это риск блокировки аккаунта провайдера, а не нарушение
  152-ФЗ; решение принято владельцем, поэтому kill-switch и fallback (SpeechKit / self-host)
  обязательны. Через шлюз уходят только обезличенный учебный текст и голос; голос — только после
  отдельного согласия пользователя, с указанием, что запись обрабатывается за рубежом.
- Применимость 243-ФЗ (с 01.03.2027) к Mnema как к вызывающему чужую модель — юрист.
- Промокоды и промо: ст. 16 ЗоЗПП (без pre-ticked), ФЗ «О рекламе» для сравнений.

## 7. Что не входит

Генерация видео; генерация изображений в первом релизе; AI-оценка произношения;
«live»-распознавание и «live»-оценка частичного ответа; email/push; свободный
агентный чат с инструментами; пометки «создано с ИИ» на контенте; лимит колод как
платный рычаг (не на старте).
