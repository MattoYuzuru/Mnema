# Бумажный интерфейс и упражнения — проверка изменений

Изменения сохраняют принятую [бумажную визуальную систему](../../../frontend/design-and-experience-2026-09.md).
Результат проверен на локальном HTTPS Identity + Learning + Media стеке с существующим
синтетическим демо-аккаунтом. Исходный checkout с незакоммиченными изменениями владельца
не изменялся: реализация находится в отдельном worktree. Развёртывание на общем сервере
не входит в [текущую границу доставки](../../../operations/local-development-delivery.md).

## Порядок работы

1. Общие токены выделения, анимаций, ширины и безопасных декоративных полей.
2. Контракты выбора нескольких ответов и серверной проверки аудиопар.
3. Общая проекция названий материалов, плееры и нативный ввод пропуска.
4. Тексты и выравнивание страниц, шаблоны провайдеров, русские legal-страницы.
5. Независимая проверка одним агентом, автоматические gates, desktop/mobile проверка,
   защищённый PR и squash после зелёных checks.

## Проверки и ограничения

- `JAVA_HOME=<Java 21> DOCKER_HOST=<Colima socket> TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE=/var/run/docker.sock ./backend/gradlew -p backend quality --console=plain`;
  оба coverage floor = 90%, фактическое покрытие Identity 92.27%, Learning 93.13%.
- `npm --prefix frontend run lint`, `npm --prefix frontend test -- --watch=false --browsers=ChromeHeadless`, `npm --prefix frontend run build`;
  267 tests, все проходят. Сборка сохраняет известные CommonJS предупреждения лениво загружаемого Mermaid.
- Все repository policy, release/security contract, disposable backup/recovery/purge проверки из frontend-quality выполнены локально.
- Identity → Learning black-box: 14 harness tests, 25 реальных HTTP сценариев и SIGINT/SIGTERM cleanup проверки проходят.
- Независимая проверка выявила старый формат recovery, перенос ответа после reconciliation/перезапуска и потерю клавиатурного фокуса в парах. Они исправлены; regression tests добавлены.
- Desktop Chrome 154, responsive viewport 390 px; для длинного пропуска отдельный тест с областью 280 px. Keyboard фокус, reduced-motion и forced-colors учтены. Физические устройства и screen reader не проверялись.
- Источники важнейших решений: [MDN selection](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::selection),
  [HTMLMediaElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement),
  [AnalyserNode](https://developer.mozilla.org/en-US/docs/Web/API/AnalyserNode),
  [scrollLeft](https://developer.mozilla.org/en-US/docs/Web/API/Element/scrollLeft),
  [Angular lifecycle](https://angular.dev/guide/components/lifecycle).
  Происхождение иконок указано в [brand README](../../../../frontend/src/assets/brand/README.md).

## Контракты и восстановление

Сохраняются стабильные идентификаторы типов упражнений; новые choice definitions используют
schemaVersion=3 и `selectionMode`/`correctOptionIds`, канонический ответ — `optionIds[]`.
Существующие immutable schemaVersion=1 definitions читаются своим прежним оценщиком.
Неизвестные сохранённые browser attempts старого формата сбрасываются; серверная сессия
и уже записанный прогресс сохраняются. Нет второго API, dual writes или v1 wrappers.

V18 расширяет ordinal варианта до integer, V19 хранит взаимодействия аудиопар с ограниченным
retention, V20 содержит восстанавливаемую приватную проекцию заголовков. Они не удаляют
материалы или доказательства прогресса. Откат поведения — отдельный исправляющий PR;
оставлять применённые additive migrations безопаснее, чем выполнять destructive down migration.
Старый клиент со скалярным choice response не совместим с новым каноническим endpoint:
клиент и Learning обновляются вместе в пределах принятого greenfield rewrite.
