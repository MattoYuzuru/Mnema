# Эпик 1: фундамент, доступ и копии

Evidence задач эпика [MattoYuzuru/Mnema#419](https://github.com/MattoYuzuru/Mnema/issues/419).
Канон: [продуктовый контракт](../../../../product/community-decks.md),
[архитектура](../../../../architecture/community-decks.md),
[refinement](../../../community-decks-refinement.md). Подробности реализации по задачам
лежат в [guide Learning](../../../../../backend/services/learning/guide.md) и
[guide Identity](../../../../../backend/services/identity-account/guide.md); пределы и
выключатели — в [runtime policy index](../../../runtime-policy-index.md).

Записано по состоянию `feat/439-integrated-check` (HEAD `80e4cfdd`, включает все
смерженные задачи ниже). Точные SHA — squash-коммиты в `main`; точные цифры gate и
ревью — в теле соответствующего PR. Evidence описывает конкретный commit и не заменяет
код и контракты.

## Production сейчас

Все функции эпика выкачены в production **выключенными**. Включаются отдельным релизом
после Share/16 и Share/17.

| Выключатель | Production | Что закрывает |
|---|---|---|
| `learning.community.public-routes.enabled` | `false` | Публичное чтение колод по коду, запросы доступа, пригласительные ссылки, превью ссылок, подача жалобы на колоду (маршруты отвечают 404 как несуществующие). |
| `learning.community.public-media.enabled` | `false` | Медиа чужой колоды для гостей и вошедших. |
| `learning.community.forks.enabled` | `false` | Создание копий («Добавить к себе»). Уже существующие копии работают. |
| `learning.community.complaints.enabled` | `true` | Подача жалоб. Включена заранее: жалоба должна работать раньше первой публичной колоды. Сам маршрут колоды при этом остаётся за `public-routes`. |

Файлы конфигурации production в репозитории эти ключи не переопределяют, действуют значения по
умолчанию из `application.properties` (секреты окружения `prod` в этой записи не читались). Файлы хоста для превью ссылок (nginx) установлены до релиза
Share/14. Миграции V49–V57 применены в production. Миграция V58 (Share/15) выкатывается
релизом Main CI `38126078458`; на момент записи он ещё шёл.

## Что не проверено к этому моменту

- Настоящие вспомогательные технологии (VoiceOver, NVDA) и Safari/Firefox на новых экранах.
- Системное меню «Поделиться» на телефоне.
- Вошедший читатель публичной колоды против настоящего backend и полный сценарий
  «публикация → гость → копия → учёба» в браузере (закрывает Share/17).
- Нагрузка сценария H (100 тыс. MAU) измерена только по частям (EXPLAIN, замеры задач),
  сквозного нагрузочного прогона нет.
- Задача очистки жалоб через 3 года ([#409](https://github.com/MattoYuzuru/Mnema/issues/409)):
  схема держит контракт, сама задача не написана.
