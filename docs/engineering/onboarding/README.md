# Онбординг Mnema

Онбординг реализован (OB-E1…E4) и с 2026-10-19 включён в production: «Начало пути» с коротким туром, «Путь Mnema»
(13 вех) и недельный ритм. Политика ПДн 1.8 от 19 октября 2026 (раздел 16 «Знакомство с сервисом, «Путь» и ритм»)
описывает эти данные. Здесь — поведение и устройство того, что есть сейчас; статус работ ведут Issues и PR, не файлы пакета.

## Что включено в production

Значения — [`deploy/production/compose.yaml`](../../../deploy/production/compose.yaml), настройки и их значения по умолчанию —
[guide Learning](../../../backend/services/learning/guide.md) (разделы «Onboarding …»).

| Возможность | Флаг | Production |
|---|---|---|
| Предложение «Начала пути» и тур | `learning.onboarding.enabled`, `eligible-from` | включено; `eligible-from` = 2026-10-19T00:00:00Z |
| Группа сравнения (holdout) | `learning.experiments.onboarding_v1` (`LEARNING_ONBOARDING_EXPERIMENT_ENABLED`, `control:15,tour:85`) | включена; нужен `MNEMA_EXPERIMENT_SECRET` |
| «Путь Mnema»: вехи и одноразовый backfill по истории | `learning.onboarding.backfill.enabled` | включено (один запуск на версию реестра) |
| Недельный ритм | `learning.onboarding.rhythm.enabled` | включено |
| Учебная колода «Моя первая колода» | `learning.onboarding.sample-deck.enabled`, `template-id` | **выключено**: в production нет шаблона, его устанавливает владелец |
| Награда за полный «Путь» | `learning.onboarding.reward.enabled` | **выключено** по решению владельца; кампании нет |

Бесплатные ИИ-проверки в учебной колоде (`free-ai-checks`, 3) действуют только вместе с колодой. Пока ветка «На примере»
скрыта, тур и «Путь» работают без неё; ИИ-вехи и карточка «ИИ в Mnema» зависят от операторских флагов ИИ-слоя.

## Решения владельца

Журнал решений: «Q» — номер вопроса, на который владелец ответил 2026-10-14 (на эти номера ссылаются proposal и ADR).

| ID | Решение | Где действует |
|---|---|---|
| Q01 | После первого входа новичок попадает на выбранную ветку; «Найти готовую колоду» есть, когда в каталоге ≥ 4 колод | proposal, слой 1 |
| Q02 | Владелец сам готовит 10+ базовых редакционных колод (языки, программирование, инструменты); решение 2026-10-10 «стартовые колоды не готовим» пересмотрено | proposal, слой 1; [community decks](../../product/community-decks.md) |
| Q03 | Досрочное завершение тура — удержанием ~2 с, как удаление; «одно нажатие + Вернуть» отклонено | proposal, слой 2; [styleguide](../../frontend/styleguide.md) |
| Q04 | До 3 бесплатных ИИ-проверок в учебной колоде за счёт Mnema | proposal, слой 3; ADR-ONB-003 |
| Q05 | Тема учебной колоды — «Как устроена память» | proposal, слой 3 |
| Q06 | Опрос: цель, интересы, опыт с карточками, дней в неделю; «откуда узнали» не спрашиваем | proposal, слой 1 |
| Q07 | «Недель в ритме» только в профиле | proposal, слой 4; ADR-ONB-004 |
| Q08 | Финал тура — карточка «ИИ в Mnema» без автоперехода на тарифы | proposal, слой 2 |
| Q09 | 13 вех «Пути» | proposal, слой 5; `milestones.json` |
| Q10 | Награда за 100 % «Пути» делается; действует 7 дней с момента выдачи, один раз на аккаунт | proposal, слой 6; ADR-ONB-005 |
| Q11 | В ритм засчитываются завершённые SCHEDULED и PRACTICE (REPLAY нет) | proposal, слой 4; ADR-ONB-004 |
| Q12 | Звёзды — только приветствие, поздравление и награда | proposal, слой 1 |
| Q13 | Старые аккаунты тур сами не получают; «Пройти знакомство заново» в профиле доступно всем; «Путь» виден всем; перепрохождение без предложения о скидке | proposal, «Сегменты» |

Дальнейшие решения:

- **Прототип и тексты** утверждены 2026-10-16. **Все строки, добавленные реализацией (S1–S4),** утверждены владельцем 2026-10-19.
- **Политика ПДн:** раздел утверждён владельцем; опубликован как версия 1.8 от 2026-10-19 (одобрение РКН сообщено владельцем).
- **Награда в production выключена**: кампания не создаётся, флаг не включается без отдельного решения владельца (текст и условия).
- **Учебная колода в production выключена**, пока владелец не установит шаблон (процедура — [selfhost-local](../../deploy/selfhost-local.md#sample-deck-моя-первая-колода)).
- **Базовые колоды (OB-003):** 10 колод опубликованы PRIVATE в аккаунте владельца в production; публикация как PUBLIC и полка
  «Выбор Мнемы» — отдельное решение владельца. Проверка колод на local stack (видны в каталоге, ветка «Найти готовую» появляется) открыта в Issue #519.
- Удержание завершения тура остаётся как есть (находка о клавиатурном доступе удержания, WCAG 2.1.1, в работу не берётся); Escape ставит тур на паузу.

Открыто (ответа владельца нет, поведение — как реализовано):

| Вопрос | Как реализовано сейчас |
|---|---|
| Шаблон учебной колоды опубликован на `LINK`, поэтому его владельцы-копии технически видят ссылку и могут читать шаблон | Копировать шаблон и делиться учебной колодой нельзя; принять следствие или найти иной путь доставки «Есть обновление» |
| Поздравление за 100 % показывается один раз на устройстве | На втором устройстве покажется ещё раз, пока подарок действует |
| `VOICE_ANSWER` засчитывается за любое распознавание речи, не только за ответ в занятии | Принято по умолчанию |
| Скрытые ИИ-вехи не дают тостов задним числом после включения ИИ; «Скрыть «Путь»» действует только на устройстве | Принято по умолчанию |
| Квест «Объяснить своими словами» может не дойти до вехи, если в колоде нет задания с проверкой ИИ | Нужен серверный признак — отдельная задача |
| Проверка тура скринридером (VoiceOver/NVDA/TalkBack) на реальных устройствах | Не выполнялась; автоматические проверки (клавиатура, reduced motion, forced colors, 320 px при 200 %) пройдены |
