## Объём и сессии

Сессии и промпты: S0 подготовка → S1 OB-E1 → S2 OB-E2 → S3 OB-E3 → S4 OB-E4 ([prompts](prompts.md)),
фактический статус — [progress](progress.md). Владелец может поставить онбординг вторым-третьим
приоритетом: каждая сессия сама проверяет актуальность базы и предыдущей работы.

Ориентир — четыре длинные автономные сессии по эпикам (≈ 40–63 ч активного агентного времени
вместе), плюс время владельца на прототип, тексты, шаблон и юридическую проверку. Это planning
estimate по знакомой архитектуре, не измеренная скорость. OB-E1 и OB-E2 разумно вести одной
двухсессионной очередью: ветка «На примере» — главная для новичков, пока Сообщество пустое.
OB-301 может идти параллельно OB-102 (разные файлы: backend против frontend).

## Definition of Ready

Свежий main (эпики Сообщества 3–4 в нём), утверждённые вид и тексты для UI-задач (OB-001), утверждённые планы колод для
OB-202/OB-003, известные миграции и контракты, rollback boundary. Решения владельца получены 2026-10-14.
