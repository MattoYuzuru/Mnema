Карта составлена read-only по коду эпиков Сообщества 3 и 4 (`f4f5e636`, теперь в main).
Пути кода ниже перед реализацией перепроверяются в свежем main.

## Поверхности, по которым пойдёт тур

Шапка: «Мои колоды · Сообщество · Новая колода · Профиль». Маршруты: `/community` (публичный,
выключатель `COMMUNITY_LAUNCHED=false` прячет только входы), `/d/:code` (публичный просмотр,
«Добавить к себе»), `/decks`, `/decks/new`, `/decks/:id` (хаб колоды), `materials/new`
(composer с ИИ или простой редактор), `exercises/generate`, `capture` («На потом»), `workshop`,
`study`, `/plans`, `/profile` (разделы: О вас, Публичный профиль, интересы, ИИ-бюджет, Тариф,
Распознавание речи, Уведомления, Пароль). После входа пользователь возвращается на `returnUrl`.

## Чего нет

- Spotlight-тура, движка шагов, состояния «прошёл / пропустил / перепройти».
- Чек-листа освоения продукта, вех, достижений.
- Пользовательской серии дней. В домене есть только `correctStreak` цели для строгости
  `ai-semantic`; продуктовые документы прямо запрещают оптимизировать opens/streak
  ([product direction](../../product/product-direction-v2.md), [design](../../frontend/design-and-experience-2026-09.md)).
- Учебной колоды-примера и шаблонов. Решение 2026-10-10: стартовые колоды **каталога** не
  готовим, поэтому на запуске Сообщество может быть пустым.
- Системной выдачи персонального промокода.
- Тёмной темы: продукт светлый, бумага и чернила. «Звёздное небо» — новая поверхность.

## Принятые ограничения, которые план не нарушает

- Гость видит Сообщество; приватные колоды в ИИ не отправляются; цель не меняет права, лимиты и цены.
- Learning владеет доменом, профилем цели, уведомлениями и промо; Identity — аккаунтом и
  claims (`mnema_new_account` < 48 ч, `mnema_trusted`).
- Синхронные инкрементальные writers в транзакции события (`DeckEngagement`,
  `NotificationPublisher`) — принятый idiom вместо отдельной outbox-очереди.
- Последняя миграция эпика 4 — `V71__topic_interests.sql`; номер новой миграции брать
  по inventory свежего main.
