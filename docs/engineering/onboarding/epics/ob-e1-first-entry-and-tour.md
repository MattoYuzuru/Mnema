# OB-E1 — Первый вход: «Начало пути», опрос и тур

## Зачем

Новый пользователь из рекламы попадает в пустой продукт и не знает, с чего начать; вопрос о цели
и выбор интересов уже есть, но разбросаны по страницам. Нет способа показать основной сценарий
«колода → материал → занятие» тем, кому это нужно, и не мешать тем, кому не нужно.

## Результат

Новый аккаунт один раз видит «Начало пути»: приветствие, опрос до 4 вопросов, выбор ветки,
короткий spotlight-тур с паузой, завершением, отменой и перепрохождением из профиля. Существующие
пользователи не получают навязанного тура. Измеряется активация против holdout.

## Входит в scope

[OB-101](../tasks/ob-101.md) journey contract/schema/API;
[OB-102](../tasks/ob-102.md) spotlight-движок и элементы стайлгайда;
[OB-103](../tasks/ob-103.md) «Начало пути», опрос, координация поверхностей;
[OB-104](../tasks/ob-104.md) ветки «Сообщество» и «Своя колода», финал, перепрохождение;
[OB-105](../tasks/ob-105.md) измерение, тексты политики, интегрированная проверка.

## Не входит

Учебная колода (OB-E2), «Путь» и вехи (OB-E3), ритм и награда (OB-E4), изменение лендинга и
регистрации, изменение посадочной страницы после входа сверх ответа на вопрос Q01.

## Зависимости и решения

[OB-001](../tasks/ob-001.md) утверждённые дизайн и тексты; ответы Q01–Q03, Q06, Q08
([questions](../questions.md)); [RFC](../rfc.md) R1–R4; [architecture](../architecture.md) §3–4, §8;
[ADR-ONB-001](../adr/adr-onb-001-tour-engine.md). Ветка «Сообщество» требует интегрированных
эпиков 3–4 Сообщества (каталог, интересы) и базовых колод владельца ([OB-003](../tasks/ob-003.md));
без них она скрыта, эпик всё равно полезен.

## Критерии завершения

- [x] Новый eligible аккаунт видит «Начало пути» ровно один раз; существующий — нет. — OB-101/OB-103, harness [результаты](../../evidence/onboarding/ob-e1/onboarding-results.json) (S1).
- [x] Опрос переиспользует API цели и интересов; пропуск каждого вопроса равен по усилию ответу. — OB-103 (S1).
- [x] Тур ≤ 4 шагов на ветку, action-gated шаги ждут действия, пауза и продолжение на другом устройстве. — OB-104, harness (второе устройство) (S1).
- [x] Досрочное завершение удержанием (как удаление), пропуск — равной кнопкой; перепрохождение из профиля
  доступно всем и работает на своих данных. — OB-102/OB-104, harness `onboarding_hold`, `onboarding_skip`, `onboarding_replay` (S1).
- [x] Тур, промо-окно и опрос никогда не перекрывают друг друга и занятие. — OB-103 (S1).
- [ ] Клавиатура, скринридер (VoiceOver/NVDA smoke), 320 px, forced-colors, reduced motion — evidence. — S1: всё, кроме VoiceOver/NVDA smoke ([handoff S1](../../evidence/onboarding/ob-e1/handoff-session-1.md)).
- [x] Holdout назначается сервером, активация считается; полный gate свежий. — OB-105, [handoff S1](../../evidence/onboarding/ob-e1/handoff-session-1.md) (S1).

## Метрики и evidence

Доли started/skipped/completed по шагам, время до первого занятия, активация 7 дней в
вариантах — только агрегаты. Desktop/mobile скриншоты, a11y-отчёт, контрактные фикстуры.

## Риски и rollback

Навязчивость (лечится равным пропуском и паузой), поломка тура при смене вёрстки (стабильные
anchors + тест реестра), перекрытие поверхностей. Rollback: `learning.onboarding.enabled=false`
скрывает «Начало пути» и тур; данные journey сохраняются; старый вопрос о цели снова показывается.
