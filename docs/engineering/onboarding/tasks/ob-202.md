# OB-202 — Содержание шаблона и установка в окружение

## Контекст и результат

Учебная колода ценна содержанием: она должна показать возможности и сама быть полезной.
Результат: шаблон «Как устроена память» (Q05), собранный в MnemaDeckStudio, установленный в local и,
по отдельному поручению, в production как колода редакции `SAMPLE_TEMPLATE`, и runbook его обновления.

## Scope и ограничения

- Инструмент: `/Users/yuzuru/Projects/MnemaDeckStudio` — прочитать его `AGENTS.md`/`README.md`, план через
  скилл `mnema-deck-plan`, утверждение плана **только владельцем** (`studio approve` не выполнять самому),
  сборка `mnema-deck-build`. Платные вызовы провайдеров и записи через creator API — только по
  утверждённому плану; видимость PRIVATE.
- Простой язык: колода показывает, что можно сделать, а не учит всему.
- 8–12 материалов: форматирование (жирный, курсив, списки, цитата, ссылка), картинка, аудио,
  конспект, пары «термин — определение», правило с примером. Медиа только с подтверждённой
  лицензией или собственные; provenance рядом.
- Упражнения ≥ 5 механик каталога; 1–2 задания с ИИ: «объясните своими словами» (`ai-semantic`) и ответ
  голосом (Q04); у них есть самопроверка, если ИИ выключен (правило DeckStudio «стартовые упражнения
  работают без платной ИИ-проверки»); короткое занятие ≤ 4 упражнений в первый день.
- Источник истины — pack DeckStudio в native content формате; установка — через обычный API
  авторинга/публикации от аккаунта редакции (как делает DeckStudio), не SQL-вставки. Скрипт установки идемпотентен (по ключу материала).
- Текст проходит редактуру; без «создано ИИ» пометок (решение владельца AI layer).
