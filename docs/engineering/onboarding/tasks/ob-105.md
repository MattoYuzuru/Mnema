# OB-105 — Измерение, holdout и завершение OB-E1

## Контекст и результат

Без контрольной группы нельзя понять, помогает ли тур активации или только занимает время.
Результат: эксперимент `onboarding-v1` через существующий ExperimentService, серверный подсчёт
активации, агрегаты в кабинете владельца, интегрированная проверка эпика и handoff.

## Scope и ограничения

- Назначение варианта сервером по аккаунту при первом `GET /api/onboarding`; control не получает
  автопредложение тура, но может открыть его из профиля и видит «Путь».
- EXPOSURE — решение показать «Начало пути»; CONVERSION — первое SCHEDULED-занятие ≤ 7 дней;
  guardrail — занятия в 2 разных днях ≤ 14 дней. Holdout 10–20 % и постоянный ([research §9](../research.md#9-активация-и-эксперимент)); доля и порог — в runtime policy index.
- Только агрегаты; без текстов, названий, поисков. Счётчики шагов тура — метрики Prometheus по
  `stepKey`/`action`, без аккаунта.
- Интегрированная проверка: local full stack, обе ветки, a11y-набор, mobile, отказ API, флаги.

## Критерии приёмки

- [x] Вариант стабилен для аккаунта, события не дублируются, отказ отправки не мешает странице. — `OnboardingCohortTest` (когорта в строке, EXPOSURE после коммита), `ExperimentHttpTest` (server-only) (S1).
- [x] Отчёт владельца показывает активацию по вариантам с размером групп и предупреждением о малой выборке. — `OnboardingHttpIntegrationTest` (отчёт), `/manage/onboarding` (`admin-onboarding-page.component.spec.ts`) (S1).
- [x] Чек-лист критериев OB-E1 закрыт evidence; полный gate на точном commit. — [handoff S1](../../evidence/onboarding/ob-e1/handoff-session-1.md) — кроме VoiceOver/NVDA smoke (S1).
- [x] Handoff: HEAD/base, AC, gate, rollback, непроверенное, следующий шаг. — [handoff S1](../../evidence/onboarding/ob-e1/handoff-session-1.md) (S1).
