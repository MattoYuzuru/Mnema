# OB-102 — Движок spotlight-тура и элементы стайлгайда

## Контекст и результат

Нужен переиспользуемый движок шагов с затемнением, вырезом и карточкой, на котором построены
основной тур, ветки и побочные квесты. Результат: `core/onboarding/` (`TourEngine`, `JourneyStore`,
директива `mnTourAnchor`), компоненты `app-tour-card`, `app-night-sky`, токены — сначала в
`/styleguide` ([ADR-ONB-001](../adr/adr-onb-001-tour-engine.md), architecture §8).

## Scope и ограничения

- Нативные `<dialog>`, Popover API, `inert`, `ResizeObserver`, своя live-region; `@angular/cdk` в проекте
  нет и не добавляется без разрешения (ADR-ONB-001). Signals для состояния, без неограниченных подписок.
- Вырез — SVG-маска с отступом и скруглением; следование за целью — `ResizeObserver` + scroll/rAF;
  карточка — connected position с fallback, на узком экране — нижний лист.
- Шаг: `{key, route?, anchor, title, body[], gate, placement}`; gate `next` или `action:<event>`
  (событие публикует целевой компонент через сервис, не DOM-клики).
- Escape → PAUSE, клик по вуали ничего не делает.
- «Завершить знакомство» — удержание (Q03): первое нажатие взводит, вместо подписи появляется новый
  знак `app-glyph name="hold"` (палец удерживает кнопку), удержание 2 с завершает, отпускание раньше —
  отмена; pointer и клавиатура (удержание Enter/Space) — как у `app-hold-to-delete-button`. Общий код
  удержания не копируется: компонент удаления обобщается параметрами (длительность, знак вместо
  подписи, доступное имя) или выделяется общий hold-примитив; тесты удаления остаются зелёными.
- Правило 4 стайлгайда дополняется: удержание — необратимое удаление и досрочное завершение знакомства.
- Reduced motion: без анимации выреза и мерцания; forced-colors: рамка `Highlight` вокруг цели,
  вуаль `Canvas` с прозрачностью не используется для смысла.
- Анкоры по стабильным ключам; реестр ключей проверяется тестом против определений туров.

## Критерии приёмки

- [x] Стайлгайд показывает карточку шага, ночную поверхность, вуаль с вырезом, паузу и кнопку завершения
  удержанием во всех состояниях — с подписью «когда использовать»; правило 4 обновлено. — `/styleguide` «Знакомство» (`sg-tour.component`), [styleguide.md](../../../frontend/styleguide.md), правило 4 (S1).
- [x] Клавиатура: Tab внутри карточки и цели, Escape, Enter/Space на «Дальше»; фокус после смены шага на заголовке карточки. — specs движка/карточки, harness `--onboarding` ([результаты](../../evidence/onboarding/ob-e1/onboarding-results.json)) (S1).
- [ ] Скринридер объявляет «Шаг N из M» и заголовок; цель доступна по имени. — S1: дерево доступности и live-region проверены в harness ([a11y](../../evidence/onboarding/ob-e1/onboarding-a11y.json)); VoiceOver/NVDA smoke не выполнялся — открыто.
- [ ] Цель вне экрана прокручивается; изменение размеров/скролл не рассинхронизируют вырез. — S1: чистые функции геометрии (`tour-geometry` specs) и ручная проверка в браузере; real-browser сценария resize/scroll нет — открыто.
- [x] Отсутствующий anchor через 4 с даёт текстовый вариант шага, без падения. — `tour-engine.service.spec.ts` (4 с, текстовый вариант) (S1).
- [x] Контраст новых токенов проходит `color-contrast.spec`; 320 px без горизонтальной прокрутки. — `color-contrast.spec.ts`; 320 px без прокрутки — harness ([результаты](../../evidence/onboarding/ob-e1/onboarding-results.json)) (S1).

## Проверка

Component tests (Vitest/Angular testing по проекту), a11y-проверки, ручной VoiceOver smoke,
скриншоты; full frontend gate.

## Риски и rollback

Перекрытие других overlay (z-order с `popover`/`<dialog>` других компонентов), утечка `inert`. Движок неактивен без
определений тура — rollback не нужен.
