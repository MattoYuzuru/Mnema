# OB-301 — Реестр вех, ledger и запись в доменных writers

## Контекст и результат

Результат: реестр вех (enum + `contracts/onboarding/milestones.json`), таблица `account_milestone`,
`MilestoneRecorder` с `@Transactional(MANDATORY)`, вызовы в доменных writers, новый kind
уведомления `PATH_MILESTONE` (route `PATH`) и заполнение `milestones`/`path` в `GET /api/onboarding`
([ADR-ONB-002](../adr/adr-onb-002-milestones.md), architecture §5).

## Scope и ограничения

- Список вех — по решению Q09; каждая веха: key, target, chapter, условие видимости (например,
  `COMMUNITY_COPY` скрыта при пустом каталоге), route key для клиента.
- Writer — одно выражение upsert; уведомление публикуется только при переходе в `achieved_at`.
- Условия: только SCHEDULED для занятий; `purpose=USER` для авторских вех; учебная колода считает
  FIRST_DECK/FIRST_SESSION; практика/повтор/чужие колоды — нет.
- Notifications contract: добавить kind и dedupe key `path:<key>`; клиенты, не знающие kind,
  игнорируют его (уже правило контракта).
- Inventory-тест: каждая видимая веха имеет точку вызова и фикстуру.

## Критерии приёмки

- [x] Параллельные события дают одну строку и одно уведомление. — `MilestoneRecorderIntegrationTest.parallelIdenticalEventsGiveOneRowAndOneNotification`, `parallelIncrementsOfACounterSaturateAtTheTargetAndAnnounceOnce`; [S3](../../evidence/onboarding/ob-e3/handoff-session-3.md)
- [x] Откат доменной транзакции откатывает веху. — `aRolledBackActionLeavesNoMilestoneNoNotificationAndNoCount`, `MilestoneWritersIntegrationTest.aDomainActionThatFailsAfter…`, `MilestonePublisherFailureIntegrationTest`
- [x] Счётная веха растёт до target и не дальше; `achieved_at` ставится один раз. — `aCounterGrowsToTheTargetAndSaturatesThere…`, `theStagesOfANoteNeverGoBack…`
- [x] Горячий путь занятия: измерено добавочное время (EXPLAIN + микротест), без регресса p95 существующих тестов. — [hot-path](../../evidence/onboarding/ob-e3/hot-path.md): +1 PK-чтение в установившемся режиме; число выражений проверяет `MilestoneHotPathIntegrationTest`

## Проверка

Real-DB integration по каждой вехе, контрактные фикстуры, full backend gate.

## Риски и rollback

Запись в чужом writer ломает его транзакцию — выражение без внешних зависимостей, тест отказа.
Rollback: флаг клиента скрывает «Путь»; запись безвредна.
