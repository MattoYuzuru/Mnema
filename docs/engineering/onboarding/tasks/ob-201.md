# OB-201 — `deck.purpose`, запреты и `SampleDeckService`

## Контекст и результат

Учебная колода — копия шаблона, которую нельзя расшарить и которая не влияет на каталог.
Результат: колонка `deck.purpose` (`USER`, `SAMPLE_TEMPLATE`, `SAMPLE`), частичный unique index
одной живой учебной колоды, `POST /api/onboarding/sample-deck`, запреты публикации/доступа и
исключения engagement/catalog/interests ([ADR-ONB-003](../adr/adr-onb-003-sample-deck.md), architecture §6).

## Scope и ограничения

- Копия — существующий `ForkService.copy` системным путём, источник только из
  `learning.onboarding.sample-deck.template-id`; шаблон должен иметь опубликованную ревизию.
- 409 `SAMPLE_DECK_NOT_SHAREABLE` для публикации, смены уровня доступа, ссылки, приглашений; копия
  учебной колоды кем-либо невозможна. Ошибка — в стабильной схеме RFC 9457.
- `DeckEngagement`, `CatalogOutbox`, интересы и авторские вехи проверяют `purpose` в одном месте каждый.
- `GET /api/onboarding` заполняет `sampleDeck` (`available`, `deckId`, `updateAvailable`).
- Колонка additive с default; миграция после inventory.

## Критерии приёмки

- [x] Параллельные запросы и повтор `commandId` дают одну живую колоду; после удаления — новая. — `SampleDeckHttpIntegrationTest` (8 параллельных, повтор, удаление → новая копия); local stack: 201 → 200 тот же deckId (S2).
- [x] Все shareable-команды для `SAMPLE` и `SAMPLE_TEMPLATE` (кроме публикации редакцией шаблона) отклоняются. — `SharingInventoryIntegrationTest` (все изменяющие маршруты library/fork), `DeckPurposeGuardIntegrationTest`; local stack: публикация копии и копия шаблона по коду → 409 (S2).
- [x] Никаких строк engagement/catalog/interest events от учебной колоды (real-DB тест). — `SampleDeckExclusionsIntegrationTest` (real DB, падает при снятых условиях) (S2).
- [x] Шаблон не в каталоге и не в поиске; пропущенный/неопубликованный шаблон → `available=false`. — `SampleDeckHttpIntegrationTest` (не помеченный/неопубликованный/скрытый → `available=false`); шаблон на `LINK` вне каталога (S2).
- [ ] Purge аккаунта удаляет учебную колоду как обычную. — S2: пути purge в Learning нет; TODO в `SampleDeckRepository` (учебная колода, `ONBOARDING_SAMPLE_CHECK`, receipts) за #409 — открыто.
