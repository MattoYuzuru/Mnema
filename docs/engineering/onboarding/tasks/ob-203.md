# OB-203 — Ветка «На примере», плашка и проверка ИИ в учебной колоде

## Контекст и результат

Результат: ветка тура `SAMPLE` (создание копии с ожиданием материализации → хаб → материал →
упражнения → занятие → итоги), плашка «Учебная колода» в хабе, скрытие «Поделиться» и
«Доступ…» в меню, до 3 бесплатных проверок ИИ в учебной колоде (Q04).

## Scope и ограничения

- Ожидание копии использует существующие состояния копии (`failed` + «Повторить»).
- Плашка — элемент стайлгайда (`.notice` или новый `app-sample-badge` через стайлгайд),
  текст утверждён в OB-001.
- До 3 проверок ИИ (`ai-semantic` и распознавание голоса для ответа) в колоде `SAMPLE` не списывают
  AI-бюджет и учитываются отдельной категорией usage `onboarding-sample`; лимит 3 — в runtime policy
  index; дальше — обычное списание с понятным текстом до попытки. Счётчик — на аккаунт, не на копию
  (удаление и новая копия не дают ещё 3).
- Занятие по учебной колоде — обычный Study, без особых режимов.

## Критерии приёмки

- [x] Ветка проходится end-to-end; при медленной материализации карточка ожидания доступна скринридеру. — local stack, встроенный браузер ≈ 400 px: выбор → копия → 4 шага → занятие → `COMPLETED`; ожидание копии — `role=status` (specs) — [снимки](../../evidence/onboarding/ob-e2/), [handoff S2](../../evidence/onboarding/ob-e2/handoff-session-2.md) (S2).
- [x] Меню хаба не предлагает шаринг; прямой API даёт 409 (из OB-201). — `own-deck-detail-page` specs, браузер на local stack; API 409 (OB-201) (S2).
- [ ] Первые 3 проверки бесплатны, четвёртая списывается с предупреждением; учёт виден в «ИИ-бюджет» и в кабинете. — S2: бесплатность и платная четвёртая — `SampleCheckAssessmentIntegrationTest`, `SpeechInputIntegrationTest`; подсказка до попытки — `study-sample-checks.spec.ts`; кабинет показывает операцию `ONBOARDING_SAMPLE_CHECK`; страница «ИИ-бюджет» её не показывает (бакеты тарифа не тратятся) и в браузере не проверено — открыто.
