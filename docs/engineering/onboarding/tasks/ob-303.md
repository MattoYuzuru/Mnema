# OB-303 — Страница «Путь», переходы и подсказки на месте

## Контекст и результат

Результат: раздел «Путь» в профиле (или `/profile/path` — решение OB-001), компонент
`app-path-milestone` в стайлгайде, переходы по стрелке с подсказкой без затемнения у целевого
элемента, тост вехи из уведомления `PATH_MILESTONE`, кнопка «Пройти знакомство заново».

## Scope и ограничения

- Вехи по главам; знак + слово состояния («Сделано», «2 из 3», «Ещё не начато»); полоса — `progressbar`
  с текстом; стрелка — ссылка с доступным именем «Перейти: Добавить картинку».
- Переход: route key → URL на клиенте, подсказка — `app-toggletip`-подобная немодальная карточка у
  anchor (движок OB-102 в режиме `hint`, без вуали); закрывается Escape или действием.
- Тосты: через notification center; не во время ответа (QuietZone); сводный тост при нескольких вехах
  за 30 с; формат «Путь: … · 6 из 13».
- Заметка «Новое: Путь Mnema» один раз для существующих аккаунтов.
- Auto-load правило списков не применяется (список конечный, ≤ 14).

## Критерии приёмки

- [x] Каждая стрелка ведёт в существующее место; при отсутствии anchor — текст подсказки. — `path-places`/`path-navigation`/`path-hint` specs по всем route key фикстуры; браузер: `path_hint` ([results](../../evidence/onboarding/ob-e3/path-results.json)); «Цель» в профиле добавлена (review H1)
- [ ] Состояние передано не только цветом; клавиатура и скринридер. — S3: знак + слово, `progressbar` с именем, дерево доступности и forced colors в браузере (`path_page`, [a11y](../../evidence/onboarding/ob-e3/path-a11y.json)); VoiceOver/NVDA не проверялись — открыто
- [x] Тост вехи появляется после действия вне тура и не появляется в занятии. — браузер `path_study_quiet` (тост после обратной связи, не во время ответа), `path-toasts.spec.ts` (30 с, сводный, BADGE_ONLY)
- [x] Стайлгайд содержит веху во всех состояниях. — раздел «Путь Mnema» (`sg-path`), [styleguide](../../../frontend/styleguide.md)
