# OB-103 — «Начало пути»: приветствие, опрос, координация поверхностей

## Контекст и результат

Вопрос о цели показывается inline на трёх страницах, интересы — при входе в Сообщество, промо-окно
живёт своей жизнью. Результат: единый первый вход — приветствие, опрос до 4 карточек, выбор ветки —
и `AttentionCoordinator`, который не даёт двум «громким» поверхностям появиться одновременно.

## Scope и ограничения

- Приветствие в `app-night-sky`: «Познакомиться — 2 минуты» (primary) и «Я уже знаком — сразу к делу»
  (quiet), обе одинаково доступны; пропуск → SKIP + тост со ссылкой на профиль.
- Опрос: цель (`PUT /api/learning-profile`), интересы (`app-interest-picker`, `PUT /api/community/interests`),
  опыт и цель ритма (`PUT /api/onboarding/preferences`); полоса прогресса `role=progressbar` с текстом
  «2 из 4»; «Пропустить» на каждой карточке. Если ответ уже есть (вопрос задан ранее) — карточка
  пропускается.
- Выбор ветки: «На примере» (если `sampleDeck.available`), «Найти готовую» (если каталог даёт ≥ 4
  колоды по интересам; иначе скрыто), «Создать свою».
- `GoalOnboardingComponent` не показывается eligible аккаунтам с journey; поведение для старых без изменений.
- `AttentionCoordinator`: приоритеты architecture §8; промо-окно не запрашивается, пока journey
  `IN_PROGRESS|PAUSED` или `finished_at` сегодня; ничего не появляется при `QuietZone.active()`.
- Не на admin host, не на публичных страницах гостя.

## Критерии приёмки

- [ ] Eligible аккаунт видит приветствие один раз; перезагрузка в середине опроса продолжает с той же карточки.
- [ ] Пропуск, ответ и частичный опрос корректно сохраняются в существующих API; ИИ ничего не получает.
- [ ] Промо-окно, опрос и тур никогда не видны одновременно (тест координатора).
- [ ] Ветка «Найти готовую» скрыта при пустом каталоге; «На примере» — без шаблона.
- [ ] a11y: фокус на заголовке приветствия, порядок, объявления, reduced motion.

## Проверка

Component и integration tests, контрактные фикстуры, скриншоты desktop/mobile; frontend gate.

## Риски и rollback

Двойной показ вопроса о цели старым пользователям — тест allowlist. Rollback — флаг журнала.

## Зависимости

OB-101, OB-102, OB-001; интересы эпика 4 для второго вопроса (без них карточка пропускается).
