# OB-003 — Базовые колоды каталога владельца

## Контекст и результат

Ветка «Найти готовую колоду» полезна, только если в Сообществе есть что взять. Владелец решил
(Q02, 2026-10-14) сам подготовить **10+ базовых колод**: языки (английский, итальянский, испанский,
корейский и что-то необычное), программирование и инструменты («введение в …»). Это пересматривает
решение 2026-10-10 «стартовые колоды не готовим» для каталога. Результат — колоды, собранные в
MnemaDeckStudio, приватные до выкатки, и согласованные с этим решением канонические документы.

## Scope и ограничения

- Работа ведётся в `/Users/yuzuru/Projects/MnemaDeckStudio` по его `AGENTS.md`: план `mnema-deck-plan`,
  утверждение конкретного плана **владельцем**, сборка `mnema-deck-build`; видимость PRIVATE, пока
  production недоступен для выкатки; уже есть заготовки `catalog/english-grammar-core-a1-b2`,
  `catalog/english-ngsl-1.2`.
- Каждая колода проходит порог каталога (≥ 10 материалов, ≥ 1 упражнение, описание, тема и язык) и
  правила лицензий (NC-контент не публикуется в Сообщество).
- После выкатки — публикация владельцем как PUBLIC; полка «Выбор Мнемы» — отдельное решение владельца.
- Документы: в [community decks](../../../product/community-decks.md) (раздел «Пустое состояние») и
  журнале решений владельца записать решение 2026-10-14 в актуальной интеграционной ветке, не в старом root.
