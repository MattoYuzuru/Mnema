# OB-104 — Ветки «Сообщество» и «Своя колода», финал, перепрохождение

## Контекст и результат

Движок и первый вход готовы; нужны сами туры. Результат: определения туров версии 1 для веток
`COMMUNITY` и `OWN`, финальные карточки «ИИ в Mnema» и поздравление, кнопка «Пройти знакомство
заново» в профиле, короткий тур для `experience=FAMILIAR` ([proposal](../proposal.md) слой 2).

## Scope и ограничения

- `COMMUNITY`: поиск/полка → карточка → «Добавить к себе» (action-gate по успешной копии) → хаб
  копии → «Начать занятие». Подсказка поиска после 45 с без открытия карточки; карточка «Не нашли?
  Создайте свою» после 2 минут — переход в `OWN`.
- `OWN`: название/описание → первый материал (composer с ИИ при доступном бюджете, иначе
  редактор `?write=1`) → первое упражнение → «Начать занятие».
- Каждая ветка ≤ 4 шагов; занятие проходится пользователем без вуали (тур в PAUSE на время
  занятия, возобновляется на экране завершения).
- Финал (Q08): «ИИ в Mnema» — тезис «найти или создать материал легко, трудно упорядочить и выучить»,
  бесплатные лимиты из `GET /api/plans`, ссылка «Тарифы» без автоперехода;
  поздравление в `app-night-sky`; ссылка на «Путь» (до OB-E3 — на профиль).
- Перепрохождение (доступно всем, включая аккаунты до релиза, Q13): REPLAY открывает выбор ветки без опроса; тур берёт существующие колоды
  пользователя, если ветка подразумевает новую колоду — предлагает выбор «новая/существующая».
- Шаги с отсутствующей функцией (ИИ выключен, Сообщество не запущено) заменяются текстом или пропускаются.

## Критерии приёмки

- [ ] Обе ветки проходятся end-to-end на local stack с реальными API; копия и материал реально создаются.
- [ ] Пауза на занятии и возобновление на итогах; продолжение на втором устройстве.
- [ ] Перепрохождение не меняет ответы опроса и не создаёт лишних колод.
- [ ] Тексты совпадают с утверждёнными (OB-001).
- [ ] Реестр anchors покрывает все шаги (тест).

## Проверка

Component tests определений, один browser e2e-сценарий на ветку (только где необходимо),
скриншоты; full gate.

## Риски и rollback

Хрупкость при смене вёрстки (anchor-реестр), длительность. Rollback — версия туров/флаг.
