# OB-002 — Политика ПДн для данных онбординга

## Контекст и результат

Опыт, цель ритма, состояние тура и факты вех связаны с аккаунтом и являются персональными данными
по 152-ФЗ; ответ о цели уже требует правки политики ([community decks](../../../product/community-decks.md)).
Результат — утверждённый текст раздела политики и дата его вступления до включения флагов.

## Scope и ограничения

Цель обработки (персонализация подсказок и обучения пользованию сервисом, измерение пользы
онбординга агрегатно), состав (ответы опроса, состояние тура, вехи, дни занятий для ритма),
срок (жизнь аккаунта), удаление вместе с аккаунтом, просмотр и изменение в профиле, отсутствие
передачи ИИ и третьим лицам. С 1.09.2025 (156-ФЗ) согласие, если основание — согласие, оформляется отдельно от других документов
([research §10](../research.md#10-пдн-опроса-152-фз)); выбрать основание с юристом. Не юридическая гарантия: финальный текст — владелец/юрист
([legal checklist](../../../product/russia-legal-launch-checklist-2026.md)).

## Критерии приёмки

- [ ] Текст раздела утверждён владельцем, версия и дата политики определены.
- [ ] Перечень полей совпадает с architecture §3; новых полей без правки текста нет.
- [ ] Для награды (OB-402) отдельно проверены условия акции.

**S0 (2026-10-15):** [черновик раздела политики 1.7 и перечень полей](../../evidence/onboarding/ob-prep/ob-002-policy-draft.md) — для
владельца и юриста; найденные расхождения схемы перечислены там же.

## Проверка

Сверка полей схемы и текста; docs validator.
