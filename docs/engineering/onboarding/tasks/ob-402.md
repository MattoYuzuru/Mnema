# OB-402 — Награда за полный «Путь» (gated)

## Контекст и результат

Владелец решил делать (Q10, 2026-10-14); production-включение — после проверки текста и условий (OB-002). Результат: тип кампании
`PATH_REWARD` в кабинете владельца, `onboarding_reward`, системная выдача персонального кода при
достижении 100 % видимых вех, уведомление `PATH_REWARD_READY`, поздравление с кодом и сроком
([ADR-ONB-005](../adr/adr-onb-005-path-reward.md)).

## Scope и ограничения

- Только verified (`mnema_trusted`), одна на аккаунт (`account_id` PK), kill switch, аудит, rate limit.
- Срок 7 дней с момента выдачи, дата окончания текстом, без секундного таймера; перепрохождение не выдаёт повторно; код можно ввести на `/plans`
  существующим полем промокода.
- 100 % считается по вехам, доступным Free без платного ИИ.

## Критерии приёмки

- [ ] Гонка последних вех даёт один код; неverified — ни одного; кампания off — ни одного.
- [ ] Код проходит существующую активацию; срок соблюдается сервером.
- [ ] Владелец видит выдачи в кабинете.

## Зависимости

OB-301, OB-303; OB-002 — до включения флага в production.
