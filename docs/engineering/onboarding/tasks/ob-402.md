# OB-402 — Награда за полный «Путь» (gated)

## Контекст и результат

Владелец решил делать (Q10, 2026-10-14); production-включение — после проверки текста и условий (OB-002). Результат: тип кампании
`PATH_REWARD` в кабинете владельца, `onboarding_reward`, системная выдача персонального кода при
достижении 100 % видимых вех, уведомление `PATH_REWARD_READY`, поздравление с кодом и сроком
([ADR-ONB-005](../adr/adr-onb-005-path-reward.md)).

## Scope и ограничения

- Только verified (`mnema_trusted`), одна на аккаунт (`account_id` PK), kill switch, аудит, rate limit.
- Срок 7 дней с момента выдачи, дата окончания текстом, без секундного таймера; перепрохождение не выдаёт повторно; код можно ввести на `/plans`
  существующим полем промокода.
- 100 % считается по вехам, доступным Free без платного ИИ.

## Критерии приёмки

- [x] Гонка последних вех даёт один код; неverified — ни одного; кампания off — ни одного. — `PathRewardIntegrationTest` (гонка чтений и последних вех, untrusted/null, кампания выключена/нет), `PathRewardOffIntegrationTest`, [S4](../../evidence/onboarding/ob-e4/handoff-session-4.md)
- [x] Код проходит существующую активацию; срок соблюдается сервером. — `PathRewardIntegrationTest` (погашение получателем через `POST /api/promo-codes/redemptions`, чужой — `PROMO_INVALID`, после `expires_at` — `PROMO_INVALID`), `PersonalPromoCodesTest`
- [x] Владелец видит выдачи в кабинете. — `/manage/promos` «Награда за «Путь»» (`admin-reward-campaigns` spec), `PromoCampaignHttpTest` (список выдач без аккаунтов и кода, журнал `PROMO_CAMPAIGN_*`); в браузере кабинет не проверялся

## Зависимости
