# OB-401 — Недельный ритм

## Контекст и результат

Результат: вычисление ритма недели из `study_session`, `weeks_met`/`last_met_week` в journey,
веха RHYTHM_WEEK, блок на экране завершения занятия, семь точек недели и цель в профиле, тихий
тост при выполнении цели ([ADR-ONB-004](../adr/adr-onb-004-rhythm.md), architecture §7).

## Scope и ограничения

- Завершённые занятия SCHEDULED и PRACTICE (Q11), REPLAY — нет; разные `local_study_date`, ISO-неделя с
  понедельника. Обновить формулировки exercise catalog/Study: ритм — статистика, practice по-прежнему
  без canonical credit.
- Индекс для диапазона — только после проверки существующих индексов `study_session`.
- Тексты без потерь и долга; не в шапке; reduced motion на поздравлении.
- `weeksMet` показывается только в профиле (Q07).

## Критерии приёмки

- [ ] Практика в новый день засчитывается; повторное занятие того же дня и REPLAY ритм не меняют.
- [ ] Граница недели и смена часового пояса покрыты тестами.
- [ ] `weeksMet` увеличивается один раз на неделю при гонке.
- [ ] Экран итогов и профиль показывают одинаковое значение.

## Проверка

Real-DB integration, component tests, full gate.

## Зависимости

OB-101, OB-301 (веха), цель из OB-103.
