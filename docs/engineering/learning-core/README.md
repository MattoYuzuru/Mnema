# Улучшение ядра обучения Mnema

Пакет для будущего поручения «займись улучшением core обучения», создан по запросу
владельца 2026-10-13. Задачи опубликованы как Issues в Mnema Kanban (Backlog), номера — в
[manifest](manifest.json); новый core не реализован.
Это предложенный backlog, не новый действующий Study contract. Научная польза конкретных
изменений ещё не доказана; отрицательный результат эксперимента допустим.

## Начать здесь

1. Начинать от свежего `origin/main` в отдельном worktree.
2. [Карта существующей модели](current-model.md): что уже реализовано и чего нет.
3. [Научная проверка и отвергнутые гипотезы](research.md).
4. [Предлагаемое поведение и решения](proposal.md), [миграция](migration.md).
5. [Бэклог и оценка объёма](backlog.md), [самодостаточные промпты](prompts.md).
6. [Manifest](manifest.json): local ID → номер Issue и зависимости.

## Два рекомендуемых первых эпика

| ID | Результат | Задачи |
|---|---|---|
| LC-E1 | Восстанавливаемая минимальная история обучения, с честными границами старых данных | [эпик](epics/observations.md), LC-101…104 |
| LC-E2 | Разные проверки одной цели и понятное покрытие целей, без процентов «знания» по числу упражнений | [эпик](epics/representative-practice.md), LC-201…204 |

Это две очереди инженерной работы с полезным результатом каждая. Ориентир — две длинные
сессии по десять часов для основных срезов; полный scope может занять больше.
В [оценке](backlog.md#объём-и-десятичасовые-сессии) явно отделены обязательные срезы,
резерв, последующие исследования и календарное ожидание.

Новый classifier, FSRS в production, автоматический семантический reset и новая механика
relearning не входят в обязательный результат этих двух эпиков. Они оформлены как
LC-301…304 с собственными решениями и gates. Не включать их скрытно в первые эпики.

## Что считается решением

- Текущие [Study](../../../contracts/study/README.md), [exercise catalog](../../product/exercise-catalog-v2.md),
  [workflows](../../product/authoring-and-study-workflows.md), [AI contract](../../product/ai-layer-2026-10.md)
  и root/scoped `AGENTS.md` сохраняют приоритет до явного принятия изменения.
- Запрос реализовать LC-E1/LC-E2 по этому пакету позволяет будущему агенту принять
  предложенные defaults в пределах названного scope; неоднозначное поручение не меняет канон само по себе.
- Delivery и production имеют границы root `AGENTS.md`. Подготовка этого пакета не даёт
  standing permission на публикацию, merge, prod approval или использование ответов учеников для ML.
- На старте обновить source pins и migration inventory. Исследование опирается на код
  до слияния эпиков Сообщества 3–4 (`ae556ece`) и на их ветку (`f4f5e636`).
- `Ready` достигается после проверки актуального checkout, принятия scope/defaults,
  доступности нужных зависимостей и размера reviewable change. Все задачи сейчас в `Backlog`.
