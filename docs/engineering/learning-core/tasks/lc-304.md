# LC-304 — Учиться на ошибке и проверить encoding aids

## Решение и timebox

За 2–4ч определить узкий experiment: после ошибки объяснение и повторное извлечение
через несколько других заданий; отдельно optional mnemonic aid для подходящего материала.
Выход recommendation/протокол/next issue, не universal memory booster.

## Scope и ограничения

Current one-objective/session invariant не поддерживает второй assessed вопрос той же
цели в сессии. Сравнить feedback-only follow-up и отдельную session/state модель;
не обходить uniqueness другим attemptId и не давать два независимых delayed credits.
Unsuccessful retrieval + correction может учить; cancellation/provider failure не ошибка.

Worked examples и self-explanation проверять по novice/prior knowledge. Method of loci
рассматривать для ordered recall, не для общего понимания [S17]. Не считать mnemonic
generation «выучил материал»; AI-created aids требуют source correctness.

## Критерии результата

- [ ] Pre-reveal ответ и post-feedback relearning различимы, ledger пригоден анализу зависимости.
- [ ] Новый flow не скрывает canonical effects и не ломает resume/idempotency/epoch.
- [ ] Active control/time budget/delayed test/transfer outcomes и limits описаны.
- [ ] Вариант не делать feature допустим; следующий issue не превышает reviewable scope.

## Проверка, риски и rollback

Сценарные fixtures error→feedback→retry, accessibility/focus, no-benefit outcome.
Runtime изменений в spike нет. Избыточная помощь может уничтожить самостоятельную проверку;
самый слабый input не превращается в HIGH. Выход approved experiment отдельно от полного rollout.
