# LC-203 — Измерять selection и подготовить проверку пользы

## Решение и результат

Определить, сохраняет ли новый selector eligibility/bounds/coverage и как позже проверить
retention/transfer. Выход: воспроизводимый offline report и preregistration-style pilot protocol,
не заключение «пользователи учатся лучше». Parent [LC-E2](../epics/representative-practice.md).

## Вопросы и scope

Сравнить first-eligible baseline и rotation на одинаковых synthetic inventories/sequences.
Есть ли starvation, повтор одного варианта, слабая доступность при sparse candidates,
query/workload regressions? Источник actual production selector, не его независимая копия
без equivalence fixtures. Привязать report к source/schema/selection versions и seed.

Если разрешены real observations, temporal holdout с declared missingness/assistance и
learner-level grouping; иначе явно synthetic-only. Не выводить learning lift из модели
«разные вопросы всегда лучше» — это предположение, которое требуется проверить.

Pilot: primary delayed unassisted performance при сопоставимом time budget; transfer на
новых application items отдельно; 7/30-day windows, attrition, contamination extra practice,
unit randomization/cluster uncertainty и проверенные labels. Не добавлять новый session mode.
100 users — feasibility pilot, power расчёт после variance/attrition baseline.

## Критерии приёмки

- [ ] Один seed/input даёт воспроизводимый report, реальные bounds связаны с production fixtures.
- [ ] Source/synthetic assumptions/history horizon/unknown provenance перечислены.
- [ ] Positive/negative/uncertain result допустим; no invented learning effect.
- [ ] Protocol описывает measurement before feedback, repeated-test learning и opt-in data purposes.
- [ ] Online assignment и live export не включаются автоматически; следующий executable issue определён.

## Проверка и timebox

1–2ч automated report/protocol; tests deterministic fixture/counterfactual limitations,
docs validator/full gate. Источники [research](../research.md), scope [proposal R05](../proposal.md).

## Риски и rollback

Replay старой истории не моделирует альтернативное обучение. Report легко переинтерпретировать
как causal proof; required limitations рядом с results. Runtime rollout здесь отсутствует.

## Зависимости
