# LC-201 — Выбирать разные варианты одной цели

## Контекст и результат

Due selection часто берёт первый eligible variant. Новые SCHEDULED/PRACTICE sessions
должны продвигаться по вариантам explicit objective, сохраняя budgets и pinned presentation.
Parent [LC-E2](../epics/representative-practice.md), [proposal R03](../proposal.md).

## Scope и ограничения

Versioned bounded round-robin cursor по objective-local inventory, затем stable seed/ordinal
tie-break. Cursor advances on issued new presentation и полностью проверенном пустом scan window
(ни то ни другое не утверждает assessment); REPLAY не advances rotation.
Indexed seek/wrap не застревает на одном prefix при 1000 variants.
Concurrent sessions сериализуют cursor без долгого StudyState lock; повтор start receipt
не продвигает его второй раз. Recent history diagnostic не требует full-history sort.
Если подходящий вариант может лежать вне текущего окна, bounded continuation использует
существующую preparation/refill boundary; EMPTY не объявляется до исчерпания проверяемого scope.
Retry одного cursor/window не продвигает scan повторно; issued resume остаётся immutable.

Сохраняются due → introduced → bounded new, один objective/session, exact account/deck/revision
eligibility, capabilities и media readiness. Same mechanic тоже может иметь другой meaningful
variant; content-based novelty/quality inference не входит. Единственный вариант usable.
No memory/evidence bonus за diversity; reducer не меняется. PRACTICE includeNew остаётся явным.

## Критерии приёмки

- [ ] В последовательных новых sessions с несколькими eligible variants нет постоянного выбора первого.
- [ ] 1000-variant objective с единственным eligible за первым окном 80 находится через bounded continuation, без permanent prefix starvation; wrap/disable/remove работают.
- [ ] Resume/retry не меняет вопрос; REPLAY exact source order/revisions.
- [ ] Concurrent edit/media/capability unavailable исключает непригодный вариант без ложной ошибки.
- [ ] Due/new budget, one objective/session, ACL и independent copy progress сохранены.
- [ ] Query/examined history bounded; missing old provenance имеет явный reason.

## Проверка

Deterministic selection tables + real-DB parallel sessions/refill/update/cleanup tests;
EXPLAIN 0/H, scan caps и no full scan. Existing Study/browser flows, full gate.

## Риски и rollback

Варианты одной цели могут различаться по валидности. Не повышать evidence автоматически.
Rollback policy для новых sessions, pending presentations immutable; ledger сохраняется.
