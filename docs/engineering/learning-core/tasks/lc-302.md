# LC-302 — Выбрать кандидат новой модели памяти

## Решение и timebox

За 4–8ч offline сравнить текущий baseline, простой elapsed-aware вариант и FSRS/HLR
candidate там, где input mapping валиден. Выход ADR с keep/change и следующим implementation
issue; ни production switch, ни per-user neural fitting не обязательны.

## Scope

Actual elapsed time, low-data initialization/uncertainty, assistance, recognition vs recall,
same-day dependency, variants/evaluator versions/strictness. Не отображать LOW в Easy
или CORRECT в Good без calibration. Time-series split, learner/objective holdout,
log loss/Brier/calibration strata; confounds due policy/optional practice явны.
Raw private corpus не обязателен для prototype; synthetic fit не даёт scientific proof.

Текущий reducer не выдаёт вероятность recall. Для probability metrics baseline comparator
заранее калибруется только на train либо честно отмечается unscorable; не подставлять
произвольную константу и не выдавать её проигрыш за доказательство. При synthetic-only или
непригодных outcomes результатом могут быть harness/assumptions/data gaps без numerical ranking.

## Критерии результата

- [ ] Data completeness/eligibility/model assumptions и rejected mappings задокументированы.
- [ ] Predictions сравниваются на одинаковых held-out outcomes; uncertainty дана по learners.
- [ ] Workload/due-shift dry-run, active sessions/AI fence и data-preserving rollback описаны.
- [ ] Recommendation отличает prediction improvement от causal retained learning/time.
- [ ] Следующий issue имеет frozen model/config, finite migration scope и explicit rollout gates.

## Риски и rollback

History replay не воспроизводит обучение при другой policy. Локальные missing events
не восстанавливаются; забывание не равно stricter rubric. Не reset всем users.
Новая dependency требует root permission и alternatives; optional evaluator/script не
становится permanent product compatibility path. [Migration](../migration.md) обязательна.

## Зависимости и контекст

LC-E1 observations, желательно LC-203 protocol и human grader calibration;
[S10/S11](../research.md#источники). Live data admission и prospective pilot — отдельные эффекты.
