# LC-301 — Нужен ли ещё один classifier

## Решение, scope и timebox

За 3–6ч подготовить benchmark существующего ai-semantic, deterministic rules и одного
дешёвого кандидата; рекомендовать keep/change/abstain. Локальная trained модель не является
обязательным результатом. Ни один новый dependency/provider не включается в production.

Уже есть rubric grading и 144 proposed synthetic labels. Human review этих labels и
held-out corpus — gate, а не действие, которое агент подменяет своим мнением.
Corpus включает русский язык, terse-correct/verbose-wrong, misconceptions, PARTIAL,
paraphrases, noncanonical valid answers, ASR errors, adversarial instructions.
Split по новым exercises/objectives, не случайным ответам одной задачи. Criterion-level
labels разных рубрик не становятся одним skill UUID без mapping.

Разделить train/dev/test по целям/упражнениям. Thresholds, prompts и abstention подбирать
только на train/dev, заморозить до test; после просмотра test он не остаётся untouched holdout.
Human labels следуют явной rubric; хотя бы независимый subset размечают два человека
вслепую к model output с adjudication расхождений. Если доступен только один reviewer,
это limited-reference corpus, не независимый gold; 144 agent-proposed labels тоже не gold.

## Критерии результата

- [ ] Отчёт разделяет correctness, criterion coverage, uncertainty и evaluator reliability.
- [ ] Agreement/false accept/false reject/abstention показаны отдельно для PARTIAL/языков/domains.
- [ ] p50/p95/cost/quality Pareto и correlated two-run failures измерены; safe threshold proposed.
- [ ] Human-labelled и agent-proposed subsets раздельны, rubric/annotator agreement/adjudication зафиксированы; test не используется для tuning.
- [ ] Выход recommendation/rejected options/next reviewable issue, включая вариант оставить текущую модель.

## Проверка, риски и rollback

Исходники [S12–S16](../research.md#источники), existing SemanticEvalRunner.
Real answers только с отдельно разрешённым consent/purpose; сохранять вне публичного Git.
Красота/скорость/длина не дают memory bonus. Offline branch/prompt experiment не меняет
StudyState; rollout потребует новых thresholds/human acceptance/rollback.

## Зависимости

LC-E1 desirable; human rubric calibration из существующего AI gate. Не блокирует LC-E1/E2.
