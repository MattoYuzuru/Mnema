# LC-104 — Доказать сохранность и завершить первый эпик

## Контекст и результат

Writer unit tests не доказывают history после V59 cleanup и migration recovery.
Завершить LC-E1 integrated DB/lifecycle verification, независимым review и handoff.

## Scope и ограничения

Snapshot P7D/raw P30D/diagnostic P180D/receipt TTL, account purge новых categories,
independent copies, restart/dispute/idempotency, interrupted backfill, older runtime на additive schema.
Обновить canonical Study/guide/runtime policy/privacy descriptions. Если owning lifecycle
#409 отсутствует, явно отметить production gate; не объявлять полный purge реализованным.
Tests только disposable fixtures, retained stack/volumes не трогать.

## Критерии приёмки

- [ ] После snapshot purge terminal provenance exact; existing receipts replay как раньше.
- [ ] Diagnostic expiry не удаляет canonical scheduled evidence; account removal убирает новые records по принятому lifecycle.
- [ ] Event/count reconciliation и zero state deltas приложены с HEAD/watermark.
- [ ] Older-runtime rollback/restart испытан; data tables не DROP.
- [ ] Independent review finding исправлены и повторно проверены.
- [ ] Fresh full gate; handoff содержит source pins, migration numbers, constraints и next action.

## Проверка

[Runbook](../../agent-runbook.md): backend clean quality; frontend ci/lint/test/build;
docs; relevant scripts; scoped real-DB tests. Неприменимые live-provider tests marked opt-in,
не выдавать skipped provider run за evidence. Указать exact results/receipt paths.

## Риски и rollback

Missing purge, false delivery status, старые green outputs. Stop при любом data gate failure.
Не влито или не проверено после поставки → не Done на доске.
Production/approval включаются только отдельным named mandate.
