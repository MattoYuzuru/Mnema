# LC-204 — Завершить второй эпик с проверяемым результатом

## Контекст и результат

Проверить новые selection/progress flows вместе с authoring, community copies/updates,
Study/replay/practice и retention. Deliver code/contract/UI evidence, не научное превосходство.
Parent [LC-E2](../epics/representative-practice.md).

## Scope

Canonical Study/product/guide/styleguide updates, independent review, full local gate,
real browser и bounded H plans. Existing community/AI behavior регрессируется там,
где новые boundaries пересекаются; unrelated ranking/payments/features не меняются.
Новые contract versions заменяют canonical path напрямую, без permanent `/v2` compatibility.

## Критерии приёмки

- [ ] Новые due sessions показывают варианты, resume/replay неизменны, budgets и ACL зелёные.
- [ ] Progress бизнес-матрица и duplicate/no-new-skill cases не дают false ON_TRACK/mastery.
- [ ] Retention/restart/dispute/backfill и future source updates сохраняют history/attribution.
- [ ] Desktop/mobile/keyboard/reduced motion проверены, assistive-device limitations названы.
- [ ] Report/protocol LC-203 готовы, root/canonical/scoped docs согласованы.
- [ ] Review исправления проверены; final exact-head gate свежий, delivery state правдивый.

## Проверка

[Runbook](../../agent-runbook.md): backend clean quality, frontend ci/lint/test/build,
docs/scripts, relevant disposable real-DB и browser mechanics/authoring/media scenarios.
При GitHub mandate — push, CI, protected PR/squash только после gates; production отдельно.
Receipt paths/HEAD и residual risks в handoff, без private material или огромных logs.

## Риски и rollback

Новое знание не доказано количеством mechanics. Вернуть предыдущую selection для новых
sessions; accepted observations и pending snapshots сохранить. Любой red data/security gate
останавливает delivery. Нет merge/Done при отсутствующем hosted evidence.

## Зависимости

LC-201…203; [migration](../migration.md). Ориентир 2–5ч.
