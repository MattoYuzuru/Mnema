# LC-103 — Честный backfill и экспорт

## Контекст и результат

Старая history частично пригодна, часть presentations уже удалена. Build bounded,
interruptible/idempotent backfill и private export с watermark/completeness, без fake data.
Parent [LC-E1](../epics/observations.md), [migration](../migration.md).

## Scope и ограничения

Scheduled evidence/transition order плюс exact joins где presentations сохранились.
Legacy records without exact exercise явно unknown. Practice/replay только если доступны
receipt+issued snapshot и доказуемые facts; не использовать current heads/counters вместо истории.
Disputed label исключается из mastery/retention outcome как валидная оценка, но попытка
и доставленный feedback остаются учебными воздействиями; disputed не означает false.
Original record остаётся. Unknown assistance
не становится unhinted. Backfill не создаёт assessed exposure/scheduler effects.

Пакеты bounded (default 500, adjustable within documented cap), persisted cursor/watermark,
reconciliation counts/hash, retry/resume и export schema version. Export explicit local/fixture;
production не читается без named scope. Нет raw answers или identity leakage в публикуемом отчёте.

## Критерии приёмки

- [ ] Два запуска и interrupted resume дают одинаковую projection, без duplicates.
- [ ] Snapshot purge до/во время batches не превращает unknown в ложный exact provenance.
- [ ] Live events после watermark не потеряны и не пересчитаны дважды.
- [ ] Restart/dispute/future assessment order определяется server sequence, не client time.
- [ ] Baseline state/due/streak unchanged; report exact/partial/missing counts и history horizon.
- [ ] Export имеет temporal order и stable private analysis identity, публичный output не содержит source UUID/text.

## Проверка

Synthetic 0/100 learners×10k attempts; EXPLAIN bounded reads; no unsupported capacity claim.
Real-DB backfill interruption/concurrent purge tests и deterministic export fixtures.
Full gate и docs. Source fingerprints/watermark фиксируются в evidence.

## Риски и rollback

Нельзя вернуть отсутствующие события. Stop при loss/count mismatch/unbounded scan.
Rebuild disposable projection из неизменённых sources; production accepted rows не удалять.
